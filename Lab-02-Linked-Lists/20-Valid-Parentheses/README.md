
 20. Valid Parentheses

- Platform: LeetCode
- Language: Python 3
- Status: Accepted

 Problem Description

Determine if the input string contains valid
opening and closing brackets.

The brackets must be closed in the correct order.

 Examples

Input: "()"
Output: True

Input: "()[]{}"
Output: True

Input: "(]"
Output: False

Approach

The solution uses a Stack (LIFO) to track
opening brackets and match them with closing brackets.
