
 1480. Running Sum of 1d Array

- Platform: LeetCode
- Language: Python 3
- Status: Accepted

Problem Description

Calculate the running sum of an array.

Each element in the resulting array represents
the sum of all elements up to that position.

 Example

Input:
[1, 2, 3, 4]

Output:
[1, 3, 6, 10]
