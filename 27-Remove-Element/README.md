- Platform: LeetCode
- Language: Python 3
- Status: Accepted

 Problem Description

Remove all occurrences of a specified value
from an array in-place.

Return the number of elements that remain.

Example

Input:
nums = [3, 2, 2, 3]
val = 3

Output:
2
